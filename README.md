# FlowHealth
FlowHealth är en hälsoplattform för viktuppföljning där användaren registrerar vikt och BMR för att få personliga kaloriberäkningar och prognoser. Projektet används som en lär- och demonstrationsmiljö för vårdinformatik där samma hälsodata kan representeras med SNOMED CT, lagras enligt openEHR och delas via HL7 FHIR.
